# MusicMute administrator dashboard

The dashboard is implemented as a private React + TypeScript + Vite application
backed by the NestJS administration API.

Current areas are overview, retained jobs, users, account recovery, releases,
update policy, administrators, basic processing settings, health alerts, activity,
and bounded exports. New audio processing is temporarily unavailable while the
execution architecture is redesigned.

See [scope](scope.md), [contract summary](contracts.md), and the current
[execution note](execution.md). Historical task files describe only the surviving
areas and do not authorize deployment or real-data changes.
