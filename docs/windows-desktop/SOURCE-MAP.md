## Traps the implementation must address

1. Do not claim the earlier RX 580/WinSW worker is the planned desktop product.
2. Do not rewrite all Windows ACL checks to accept any current user; preserve
   service-profile protection and add a scoped current-SID implementation.
3. Do not equate DirectML provider availability with all model nodes using GPU.
4. Do not select adapter zero or label it “fastest” without qualification.
5. Do not use Electron's embedded Node as the engine runtime without checking
   the existing worker's pinned Node requirements and native dependency ABI.
6. Do not move Firebase refresh tokens into web localStorage to reuse React UI.
7. Do not let Chrome logins, app sign-out or closing a window own fleet lifetime.
8. Do not reuse mobile direct-APK release fields as a Windows distribution model.
9. Do not test Windows paths using the development Mac's default path module.
10. Do not treat old installed-Mac or Windows-service evidence as new app proof.
