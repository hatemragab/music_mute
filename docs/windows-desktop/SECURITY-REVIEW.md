# Windows source boundary and dependency review

Review date: 2026-10-10. Scope: W30/W33 source and available code checks, preserving
all accepted features. This is not Windows penetration testing, native compilation,
an approved release/security exception or a signed release-candidate review.
The final Native Library/report source return is recorded. The final Main
pending-original validation binding and combined regression are reconciled;
source closure does not establish native protection or release approval.

## Protected data and authority

Account tokens, fleet enrollment credentials, private media, local history,
Outbox/Publication records and runtime/model activation are separate authorities.
The renderer and web page are untrusted input surfaces. Account-generation changes,
window replacement, process PID reuse, origin changes, unsupported hosts and
unknown cleanup must invalidate or retain the relevant captured authority rather
than grant a replacement. User-chosen source files and completed exports are not
cache cleanup targets.

Current-user ACLs and DPAPI are intended to protect private state from other
ordinary users. They are not a sandbox against an administrator or a malicious
process already executing as the same Windows user. DPAPI's user association and
the additional app role/peer/capability fences serve different purposes. The
review uses [Microsoft's DPAPI contract](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)
as a platform reference; actual enforcement remains W34.

## Dependency and build finding disposition

The exact dependency assessment, installed logger call sites, version/pin decision
and enforced nine-runtime-graph containment are in
[W01 development review](evidence/W01-development-dependency-review-2026-10-10.md)
and [build inputs/licenses](../../windows-desktop/docs/build-inputs-and-licenses.md).
Runtime-only audit returned zero findings. Full audit retains eight moderate
development-chain findings rooted in `sprintf-js`; the source gate excludes the
reviewed chain from every execution graph but does not fix the upstream package
or create an isolated Windows builder. At release time, recheck the advisory and
make the explicit operator/security decision. No unreviewed pin downgrade or
credential access was performed to hide that result.

The actual source build and bundle boundaries passed after the trusted outcome
and Library receiving changes. Final whole-suite results and current uncompiled Native/source fingerprints
are recorded after source freeze in W33 evidence. Public package inputs are
validated by the real loaders; unavailable signed runtime/model/app configuration,
native PEs, signing and publication are listed in
[INPUTS-AND-BLOCKERS](INPUTS-AND-BLOCKERS.md), rather than replaced with fixtures.
