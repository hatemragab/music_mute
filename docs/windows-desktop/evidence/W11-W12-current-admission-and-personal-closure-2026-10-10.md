## Trace and durable record contracts

Same GPU: approved fleet logical permit → delegated physical guard → accepted
fleet work → personal reservation fences future admission → accepted work and
positive native idle → fleet physical release → personal physical acquisition →
persist personal logical lease → model command → exact stop/native idle → private
storage cleanup → guard/logical release → previously allowed fleet wake.

Different independently qualified GPUs route to different guarded brokers;
accepted fleet work on the secondary need not exit before a primary personal
permit. Qualification remains per role; a renderer preference or numeric ordinal
cannot choose the broker. Cleanup routes stay bound to their original request so
driver/model/boot changes cannot prevent safe retirement or mint a new permit.

`fleet/gpu_broker_index` has version1/SID, at most16 exact LUID slots and an optional
legacy retirement receipt. Slots are only `gpu_broker_<16lowercasehex>`; each is
recorded opening before creation, ready after state acknowledgement, and retiring
with exact plaintext SHA and old owner before deletion. Old active records need
actual whole-Job exit. Ready-slot absence is corrupt; a known opening with no state
has never issued permission. Generic unknown files/keys are never discovered or
deleted. The caller retains genuine native SID session authority through this flow.

Personal cleanup closure retains the original committed-pair decision and exact
reuse pin/lease. It can retry acknowledged or lost-ACK substeps but cannot restart
inference, change owner/scope or remove valid committed media. False/unknown exit,
storage or lease release keeps the job busy and its intake slot reserved.

Certificate wake is distinct from a release RPC: actual exact whole-role exit
aborts that role's ungranted waiters, retires granted logical ownership and moves
its immutable route into the bounded completed ledger. A false/unknown certificate
does none of those operations. The65-owner fixture exercises the production
bank/router/broker with injected certificates; it cannot establish native exit.

| Lifecycle fault             | Positive authority / next operation                                                                                                         | Uncertain outcome                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Aborted grant/reply held    | Retain original request; owned stop→native inference idle→storage/pin cleanup→exact cancel/release nonce                                    | No model command, retain busy; no permit from transport timeout                     |
| Session crash/empty maps    | Protected index/state digest +exact old owner→actual whole-Job certificate→before-effect retirement record→delete ACK→new qualified request | Corrupt/missing-ready/live/unknown records block opening                            |
| Logout/role retirement      | Actual OS role termination and whole-Job certificate→physical keeper proof→logical state retirement                                         | Parent PID disappearance/abandonment alone cannot grant; real logout sequence unrun |
| Lost successful release ACK | Retry the same completed request/birth/generation/nonce; finish prior allowed fleet wake                                                    | No new inference or physical acquire; failed retry stays retained                   |

## Personal input, errors, scope and exact sample contracts

Fixed source extensions are `mp3,m4a,mp4,mkv,mov,webm,opus,ogg,aac,wav,flac`;
the selected source is a trusted read-only descriptor, not a renderer path.
Codec probes/encoding are owned child operations, not established by accepting
an extension. Video originals normalize to guarded AAC with bounded probe
duration; actual codec support/listening stays W34. Private staging is64 entries /
512MiB aggregate and256MiB per file; unfinished copies reserve their full declared
size. Personal execution is inclusive1,200s, with at most16 retained job slots.

Guest/null captures survive login, logout and A→B; they never become an account
save authority. Non-null A captures are rejected/retired when A's generation is
no longer current. Chrome always carries null through trusted Session dispatch.
An exact guest pair can remain locally playable while stale window autoplay is
retired. Reuse and completion never manufacture an account scope.

For an illustrative three-second source, retained ranges
`[[0,44100],[88200,132300]]` concatenate into88,200 output samples (two seconds).
Each output coordinate is contiguous; its length equals the retained source range.
The strict parser requires ordered nonoverlapping integer ranges, conservation,
at most256 ranges/four64-row IPC chunks and bounded250ms codec padding. The
untrimmed recipe requires one exact full source range. Private trimmed playback
uses that map; missing/corrupt older account maps permit known-duration standalone
voice/original behavior without a proportional mapping. A valid trimmed voice
still exports/shares; incompatible full-timeline account saving is explained.
