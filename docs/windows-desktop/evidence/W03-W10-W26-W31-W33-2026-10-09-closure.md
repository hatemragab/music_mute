Scope: W03, W10, W26, W31 and the native harness portion of W33. The linked task
checkboxes use the identifiers below. A source checkbox means executable source,
production binding and the stated portable proof; it never means Windows success.
Root owns global W33 closure and PROGRESS/RESUME/TASKS. No Windows compiler,
NSIS, signing, installation, Chrome UI, real GPU, account/service or publishing
operation ran here.

The production authority begins with the signed Electron ASAR resource index,
fixed installed publisher/hash pins or the separately protected retained worker
capsule. Fixtures inject only OS/service boundaries; they are not production
credentials, bypasses or fallback success. Native implementation receives only
closed fixed operations. App resources and external runtime role resources are
separate inventories.
