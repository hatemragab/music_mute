Reviewed 2026-10-10. This records actual receiving-source review and portable
controller/crypto/HTTP/file/jsdom fixtures. No real Windows app, native helper,

## Actual production entry and authority

[Main](../../../windows-desktop/src/main/main.ts) constructs the trusted account,
one realtime transport, usage, Library/pins, outbox and reuse factories with actual
Host/current-SID native storage, approved sealed public configuration and fixed
session/media/storage ports. [Preload](../../../windows-desktop/src/preload/index.ts)
exposes only [closed desktop commands](../../../windows-desktop/src/shared/contracts.ts).
Account/usage/Library/background saving and shared Chrome use the same captured
account authority; browser personal jobs remain null/account-free. There is no
renderer bearer/refresh token, raw private path, storage grant, free-form URL or
permission to choose a Firebase owner/generation at submission.

Main scope listeners start cloud/reuse/realtime/outbox and player/history/Library
fences before awaits. Host now invokes every current listener synchronously despite
a synchronous throw, waits every admitted settlement, emits only a fixed error and
suppresses reentrant old publication after newer authority. Source review includes
the actual configured Main ingress and callback wiring, not only typed ports.
Portable Native/HTTP/JS DOM adapters remain distinct from real Windows/live proof.
