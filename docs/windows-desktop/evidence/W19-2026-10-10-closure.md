## Production path and authority

Main builds `WindowsSilenceRunner` with the real shared Storage
`beginWrite/protectTree/trackWorkspace/reserveScratch` ports and actual
`WindowsPreparationOperations.snapshotMediaTools`; it passes that runner to
`LibraryPlaybackSources`. Only the trusted resolver's already validated, pinned
voice descriptor exposes `analyzeSilence(signal)`. Main creates the existing
PlaybackController with `WindowsBookmarkStore(context)`, actual History accounting,
account-owner/current generation and a separate installation-bound guest owner.
`powerMonitor.resume` and account invalidation call `refreshListeningOwner`.
Main's admitted-command handler dispatches the closed `PLAYBACK` command through
that controller; the sandboxed PlayerPanel sends bounded semantic controls and
actual media events. No renderer path, owner UID, native lease or arbitrary tool
command enters this chain.

## Persistent format and interaction policy

Domain v1 remains `{version:1,owner,trackId,bookmarks,skipSilencePreferred?}`;
bookmarks are `{id,seconds,title}`. Missing records default only to empty markers
and disabled skip. Valid legacy v1 is read without migration writes. The current
DPAPI multipart head, two bounded slots, observed CAS and raw-byte quarantine are
specified in [the capacity evidence](W19-listening-core.md#bookmark-dpapi-capacity-closure--2026-10-10-003438-cairo).
Explicit voice-output markers use `voice:<SHA(trackId,verified artifact)>`; they
cannot be silently treated as original coordinates if a comparison map changes.

Priority: sleep expiry → AB boundary → eligible voice quiet-range seek → normal
ended/repeat/queue advancement. Manual seek clears the pending-loop suppression;
old revision events cannot undo it. Original/voice comparison retains a common
verified original-time basis; a basis/owner change retires incompatible markers
and analysis. The current track's same-song timer survives variant/basis changes.
A new track or Stop/Quit cancels that timer. Skipping is a seek preference, never
an audio rewrite or a browser processing-recipe change.
