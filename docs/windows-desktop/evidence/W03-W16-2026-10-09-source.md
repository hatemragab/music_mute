Date: 2026-10-09. This is portable source/fixture evidence on macOS. It is not

## Source changes

- Native SDK adds fixed `inference_idle`, `share_start`, `share_inspect`,
  `share_cancel` and private ordered `share` events. Share input is a bounded
  sealed audio copy, request UUID, exact app HWND/process birth and approved app
  pin. It has no recipient/send command or arbitrary executable/path surface.
- C++ WinRT source creates its own app-owned popup/STA Share source, persists
  pending DPAPI identity/file receipts before UI, and grants cleanup only after
  ShareCompleted/ShareCanceled plus released data/handlers and exclusive exact
  file birth/hash/size proof. Pending/helper-death/timeout never implies cancel.
- Library Share controller copies the actual pinned Library artifact through
  the existing export verifier, records native handoff before invocation, and
  waits at most five minutes. Unknown ACKs and nonterminal results retain data,
  activity and persistent copy budget. Cached trimmed voice requires neither
  Prepare nor a comparison map.
- Restart uses the protected storage journal and `inspectShare`, without
  replaying ShowShareUI. Explicit positively restored prehandoff stages may be
  discarded; absent/unknown native handoff remains protected.
- Fixed cleanup acknowledgement removes completed receipt metadata only after
  actual workspace deletion. A bounded native sweep recovers lost ACKs even if
  the journal row is already gone; pending/current copies are retained and
  persistent receipt slots are capped at 64 under the SID account mutex.
- Browser authority has optional synchronous `consumersAllowed` intake fence.
  Processing/reuse/publication and fresh media grants deny during updater
  recovery or maintenance; repair transport and owned accepted operations remain.
- Session event dispatcher explicitly handles the session event kind after the
  additive Share event union. Legacy WorkerChildProcess behavior is unchanged.
