  wrappers. Bounded XmlLite rejects malformed, duplicate, elevated/uiAccess and
  DTD manifests. Sorted Unicode environment blocks have one final double NUL,
  fixed executable PATH and no inherited runtime/Node injection.
- Already-approved installed app SHA/bytes/publisher verification uses cache-only
  revocation retrieval, retaining signature/revocation policy and failure behavior.
  New package/helper/installer approval stays explicit whole-chain/network-capable.
  Package PowerShell holds the actual file through every signature/resource check.
- Pinned v26 NSIS guards now precede stock directory mutation. Its temporary
  uninstaller-generation program exits before install-directory initialization,
  preserving the real default signed-uninstaller flow. Every ExecWait checks both
  launch error and returned exit code. Signed-parent native path preflight rejects
  reparse/hardlink/foreign existing trees and retains bounded directory references
  in the installer until exit. Separate private data roots are never removal targets.
- Approval bytes are rehashed at copy; bounded file reads detect growth/birth
  replacement. Signed inventory bounds empty-directory depth/count too. ICO
  validation checks real PNG CRC/dimensions/inflation or bounded DIB payloads.
- Noto font/OFL, pinned Electron MIT and Google attribution/usage notice are
  required in staging and the actual ASAR. Their final inner paths/bytes/hashes
  enter payload evidence. Google attribution is not a logo license or OAuth approval.
- QA source digest rejects unlisted build-input file types, uses actual compiled
  module location rather than caller cwd, and filters compiler/environment injection.
- Fixed native bootIdentity is a volatile user-hive lifetime witness. It is not a
  BCD/kernel GUID or clock estimate. Existing keys must prove volatility via the
  Microsoft volatile-parent error, exact private shape/DACL and named handle
  checks. Reboot/hive unload requires requalification; old receipts fail closed.
