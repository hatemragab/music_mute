## Primary-source preflight

Read on 2026-10-10: [Zalando guidelines](https://opensource.zalando.com/restful-api-guidelines/)
security 104/105, explicit JSON/number formats and compatibility 106 apply to the
closed private protocol. REST URL/HTTP/OpenAPI registry rules do not apply to
these fixed framed Win32 operations. Ordinary frames retain 64 KiB/512-node limits;
only the authenticated fixed disk inventory/activation grammar has larger bounds.

[SetFileInformationByHandle](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-setfileinformationbyhandle)
requires DELETE access for disposition; [basic deletion](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-deletefilew)
can remain pending until all consuming handles close. The code uses basic
disposition and positive certificates, not POSIX immediate unlink.

[Pinned Node 24.18 libuv source](https://raw.githubusercontent.com/nodejs/node/v24.18.0/deps/uv/src/win/fs.c)
maps device to the low volume serial, file ID to the 64-bit FileId and FILETIME
creation/mtime/ctime to Unix nanoseconds. Native matching uses that exact mapping;
no approximate wall-clock/mtime identity substitutes were added.
