# Accepted scope coverage

All 30 accepted discussion points are retained below, with the user's later
Windows 10 22H2/x64, GPU, shared-extension and no-admin session-worker decisions
taking precedence over earlier alternatives. Task numbering is implementation
order, not a renumbering of the accepted product points. The later authorized
[Store migration](store/MSIX-MIGRATION.md) supersedes the older website-first
distribution and downloaded executable-runtime update mechanism in P27/P29;
all functional parity journeys remain required.
