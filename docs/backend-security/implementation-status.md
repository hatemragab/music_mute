## Implemented in this worktree

- Worker HTTP requests now have Redis-backed pre-auth IP/service budgets before credential lookup and post-auth principal, class, endpoint, and service budgets. The WebSocket hint upgrade uses a one-use subprotocol ticket, separate Redis budgets, a two-socket-per-machine cap, heartbeat, maximum lifetime, and explicit rejection of unknown upgrade paths. Limit failures return 429 with `Retry-After`; Redis failures fail closed.
- Public APK grant issuance has an atomic service ceiling as well as an IP limit. Public account deletion/privacy text consistently states the 15-day recovery period. Dashboard authenticated requests reject redirects.
- The public error filter emits RFC 9457 `application/problem+json` with a stable safe code and request ID. Quota-period exhaustion is a 409 conflict with `next_reset_at`; immediate rate limits remain 429 with `Retry-After`. HTTP responses set `Cache-Control: no-store` and `X-Request-Id`.
- The API wire uses snake_case JSON properties and query names, with strict rejection of legacy camelCase keys. Internal model names remain idiomatic to each language. Android, iOS, dashboard, worker, fixtures, and tests were migrated together.
- URL version prefixes and action-like routes were replaced with resource routes, without compatibility aliases. Admin worker invitations and diagnostics use bounded cursor pagination. The local OpenAPI document includes metadata, audiences, security, permissions, query serialization, schemas, responses, errors, and examples.
