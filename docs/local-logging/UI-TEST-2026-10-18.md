## Findings and fixes

- Forward workspace change notifications to the command owner. Previously a
  selected paused player still had disabled Playback menu commands. The rebuilt
  GUI enabled the correct commands; menu Stop and Command-period both removed
  the player.
- Rewind an ended native player before manual Play. The actual rebuilt GUI moved
  from the end of the 12-second tone to approximately 0.5 seconds and resumed.
  Selection/account/operation fences prevent a late seek callback from resuming
  an obsolete player.
- Treat expected account changes/cancellation as fenced cancellation rather than
  leaving a stale `ACCOUNT_CHANGED` error banner. Genuine failures remain errors.
  This behavior has source tests; a real account switch was not forced.
- Present post-processing Library finalization separately from active processing.
  Previously Home could show Starting/Cancel after the voice was ready. Task and
  cancellation behavior remain unchanged.
- Give the offline-storage input a usable accessibility label and identifier.
  In the real GUI, zero disabled Save with a validation message; three GB saved;
  Use Default restored two GB.
- Preserve validated extension request/job IDs in diagnostics. Scope inherited
  active-session identity to the matching tab/document/video/generation, rejecting
  forged, stale and unrelated events.
- Restrict diagnostic error codes to the existing approved catalog, including
  direct message/native-frame observations. A regex-shaped uppercase credential
  must not become a retained error code. Regression checks inspect every direct
  logger call and the native diagnostic frame; business frames remain unchanged.
  Diagnostic snapshots are lazy when disabled, bounded and nonthrowing; invalid
  native frames retain only explicit omission metadata. Valid native send/receive
  events expose their actual wire request ID in searchable envelope metadata.
- Replace context-free optional-operation warnings with closed operation stages,
  validated request identity, allowlisted error codes and typed HTTP status.
  Unknown details stay omitted. Optional failures do not imply the overall job
  failed. The historical warnings cannot be retrospectively attributed.
- Attach the existing private desktop/setup journals through real Vector file
  sources. The original companion/UI-only inventory missed native inference.
  Fixed paths, ownership/permission/link checks, checkpoints and field allowlists
  preserve the producer's files and privacy boundaries.
- Make private regular-file opening nonblocking before file-type validation.
  A FIFO masquerading as the debug key now fails promptly without a writer;
  valid private regular keys still work. Release collector gates remain off.
- Handle the collector's brief active-file rename gap in the diagnostic probe and
  integration reader. Retry only the expected missing-path case within existing
  deadlines; do not suppress other failures or claim success without the exact
  event. Native job cancellation and readiness also get explicit result/phase
  fields; cancellation remains separate from failure.
